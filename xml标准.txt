# 📘 NewBie-Image-Exp0.1 XML 提示词编写指南

这是一份专门针对 **NewBie-Image-Exp0.1** 模型的 XML 格式提示词编写手册，让你从“能写”到“会写”，精准控制画面。

---

## 一、XML 结构总览

```xml
<character_1>
    <n>角色名</n>
    <gender>性别</gender>
    <count>人数</count>
    <appearance>外貌特征</appearance>
    <clothing>服装描述</clothing>
    <expression>表情</expression>
    <pose>姿势</pose>
    <position>画面位置</position>
</character_1>

<character_2>（可选，多人时使用）</character_2>

<general_tags>
    <composition>构图/独占性</composition>
    <style>画风</style>
    <background>背景</background>
    <atmosphere>氛围/光影</atmosphere>
    <quality>画质标签</quality>
</general_tags>
```

---

## 二、标签详解（附常用值）

### 👤 `<character_X>` 角色标签块

| 子标签 | 作用 | 常用值示例 | 必填 |
| :--- | :--- | :--- | :--- |
| `<n>` | 角色名称/标识 | `main_character`, `heroine`, `unknown` | 推荐 |
| `<gender>` | 性别 | `1girl`, `1boy`, `1other` | ✅ 必填 |
| `<count>` | 人数 | `1`, `2`, `group` | 强烈推荐（防止多人） |
| `<exclusive>` | 独占画面 | `true`, `false` | 推荐（防多人） |
| `<appearance>` | 外貌特征 | `long_hair, blue_eyes, twintails, ahoge, blush` | ✅ 必填 |
| `<clothing>` | 服装 | `school_uniform, serafuku, pleated_skirt, knee_socks, loafers` | 推荐 |
| `<expression>` | 表情 | `smiling, open_mouth, blush, crying, angry, serious` | 推荐 |
| `<pose>` | 姿势 | `standing, sitting, lying, kneeling, running, jumping` | 推荐 |
| `<position>` | 画面位置 | `center, left, right, foreground, background` | 多人必填 |

**完整示例（单人）**：
```xml
<character_1>
    <n>heroine</n>
    <gender>1girl</gender>
    <count>1</count>
    <exclusive>true</exclusive>
    <appearance>long_hair, silver_hair, blue_eyes, twintails, ahoge, pale_skin, medium_breasts</appearance>
    <clothing>school_uniform, white_blouse, red_ribbon, pleated_skirt, knee_socks, brown_loafers</clothing>
    <expression>smiling, blush, looking_at_viewer</expression>
    <pose>standing, hands_behind_back</pose>
    <position>center</position>
</character_1>
```

---

### 🎨 `<general_tags>` 通用标签块

| 子标签 | 作用 | 常用值示例 | 推荐强度 |
| :--- | :--- | :--- | :--- |
| `<composition>` | 构图/独占性 | `solo, only_one_person, no_other_people, fully_visible` | ⭐⭐⭐⭐⭐ |
| `<style>` | 画风锁定 | `anime_style, japanese_anime, clean_lines, cel_shading` | ⭐⭐⭐⭐⭐ |
| `<background>` | 背景 | `classroom, city_street, sunset_sky, simple_background` | ⭐⭐⭐⭐ |
| `<atmosphere>` | 氛围/光影 | `bright, studio_lighting, soft_lighting, dramatic` | ⭐⭐⭐ |
| `<quality>` | 画质标签 | `highres, absurdres, masterpiece, best_quality` | ⭐⭐⭐⭐⭐ |

**完整示例**：
```xml
<general_tags>
    <composition>solo, only_one_person, no_background_characters, no_extra_limbs, fully_visible</composition>
    <style>anime_style, japanese_anime, vibrant_colors, cel_shading, clean_lines, sharp_edges, thick_outlines</style>
    <background>classroom, desk, window, sunlight_streaming_in</background>
    <atmosphere>cheerful, bright, soft_shadows, warm_lighting</atmosphere>
    <quality>highres, absurdres, masterpiece, best_quality, very_safe</quality>
</general_tags>
```

## 三、核心技巧：解决你的痛点

### 🎯 技巧1：防止多人/残肢（你的核心需求）

在 **`<composition>`** 中强制声明独占性：
```xml
<composition>solo, only_one_person, no_other_people, no_background_characters, no_extra_limbs, no_floating_limbs, no_cropped_bodies, fully_visible, no_off_screen_parts</composition>
```

### 🎯 技巧2：用负面标签“反向锁定”

在 XML 内部也可以声明“不要什么”：
```xml
<appearance>no_glasses, no_hat, no_tattoo, no_mole</appearance>
```

### 🎯 技巧3：多角色精确控制

```xml
<character_1>
    <n>heroine</n>
    <gender>1girl</gender>
    <appearance>long_blonde_hair, blue_eyes</appearance>
    <position>left</position>
</character_1>

<character_2>
    <n>hero</n>
    <gender>1boy</gender>
    <appearance>short_black_hair, red_eyes</appearance>
    <position>right</position>
</character_2>

<general_tags>
    <composition>two_characters, facing_each_other</composition>
</general_tags>
```

### 🎯 技巧4：权重控制（紧急修正）

当某些属性不够明显时，用括号加权重：
```xml
<appearance>(blue_eyes:1.2), (long_hair:1.1), twintails</appearance>
```

### 🎯 技巧5：风格锁定“三重保险”

日漫风格不够稳定时，同时写三个地方：
```xml
<!-- character 里 -->
<appearance>anime_style, anime_eyes</appearance>

<!-- style 里 -->
<style>anime_style, japanese_anime, anime_screencap</style>

<!-- quality 里 -->
<quality>anime, anime_art, anime_girl</quality>
```

## 五、常见问题速查表

| 问题 | 解决方案 |
| :--- | :--- |
| 出现多人 | 加 `<count>1</count>` + `<exclusive>true</exclusive>` + `<composition>solo, no_other_people</composition>` |
| 出现残肢/浮空手 | `<composition>no_extra_limbs, no_floating_limbs, fully_visible</composition>` |
| 画面太写实 | `<style>anime_style, cel_shading</style>` + 负面词 `photorealistic, realistic, 3d` |
| 线条不够干净 | `<style>clean_lines, sharp_edges, thick_outlines</style>` |
| 颜色太灰/太素 | `<appearance>vibrant_colors</appearance>` + CFG 调到 7.5-8.0 |
| 面部画崩 | `<expression>from_below</expression>` 或 `looking_at_viewer` 能提升面部准确性 |
| 背景太简单 | `<background>detailed_background</background>` + 具体描述 |

---

## 六、最后的叮嘱

1. **XML 不是万能的**：它只是组织标签的一种方式，底层模型仍然吃的是 Danbooru 标签。保持标签简洁、常用、符合数据分布。

2. **`solo` > `1girl`**：在 Danbooru 模型中，`solo` 对“单人”的控制力远强于 `1girl`。你的模板里一定要有 `solo` 或 `only_one_person`。

3. **先验证后批量**：用一个固定种子 + 精简模板测试标签是否生效，再展开到完整 XML。

4. **保持 `<appearance>` 不长于 15 个标签**：太多标签会让模型“注意力分散”，反而不如少而精。
