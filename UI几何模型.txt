【当前定稿模型】侧栏 = 聊天窗口左侧外面的独立窗口
────────────────────────────────────────────────────────────────

        ┌──────────────┐   ┌────────────────────────────────┐
        │              │   │  ◀            ＋   ≡          │  ← 聊天窗口标题栏
        │   侧 栏       │   ├────────────────────────────────┤
        │  （独立窗口）  │   │                                │
        │              │   │        聊天内容（气泡）          │
        │  120 × H     │   │                                │
        │              │   │        420 × H                  │
        │              │   │                                │
        │              │   ├────────────────────────────────┤
        │              │   │  [输入框...............] [发送]  │
        └──────────────┘   └────────────────────────────────┘
         x = chat.x - 120            chat.x, 宽 420, 高 H

  规则（已实现）：
   1. 侧栏宽 120px（设置里可调 80~300），高 = 聊天窗口高 H，两者顶边 y 对齐。
   2. 侧栏 x = 聊天窗口 x − 120；两者不重叠、不遮挡。
   3. 聊天窗口宽 420、高 H：**完全不受侧栏影响**（内部布局只有聊天区）。
   4. 拖动聊天窗口 → 侧栏跟着走；缩放聊天窗口 → 侧栏跟着变高。
   5. 如果聊天窗口贴到屏幕最左边（侧栏会被挤出屏幕）→ 侧栏自动改贴聊天窗口右侧。
   6. 聊天窗口隐藏/关闭 → 侧栏一起隐藏（不会孤零零留在桌面上）。
   7. 启动时：侧栏等聊天窗口摆好位置后才出现（不会先在角落自己冒出来）。
   8. 显隐：聊天窗口标题栏最左边的 ◀/▶ 按钮。

【1.9.0 新增定稿】消息气泡几何（聊天区内部）
────────────────────────────────────────────────────────────────
（流程照旧：先在对话里给出这份几何模型 → 你回「对，就按这个改」→ 才动代码）

        聊天窗口 420 × H
          └─ chat_layout 内边距 左右各 10 → 内容宽 400
              ┌──────────────────────────────┬──────────┐
              │                        气泡块 │ 头像 34  │ ← 用户侧
              │  文字从左边起，换行后仍然齐左   │ +间距 14 │
              └──────────────────────────────┴──────────┘
               气泡最大可用宽 = 400 − 48 = 352px（扣滚动条约 340）

  规则（1.9.0 已实现）：
   1. 一行两个格子：内容格（宽度自适应）+ 头像列 48px（= 头像 34 + 间距 14）。
   2. 用户侧：头像贴内容右边界，气泡块紧贴其左；桌宠侧镜像（头像在左，气泡在其右）。
   3. 气泡宽度跟内容走 —— 短消息得到短气泡，不铺满整行。
   4. 气泡内**所有行都齐左**。这是本次真正修掉的观感问题：旧写法把
      「靠边」和「文字对齐」都交给外层 td 的 align，续行会右对齐、左边参差。
   5. 气泡底色 / 内边距(8×12) / 圆角(12) 写在内层 td 上；无底色(transparent)
      时不下发内边距，保持旧观感。

  实测数字（tools/dev_tests/_test_a190.py，透明画布量不透明像素外框）：
   · 用户侧头像最右不透明像素 ≥ 388（内容宽 400）
   · 桌宠侧头像最左不透明像素 ≤ 12
   · 短消息「好」气泡宽 61px，未铺满 400px
   · 多行消息逐行起点离散度 p90−p10 = 0px（旧写法 312px）
   · 有底色的短气泡宽 70px，旧写法 46px —— 差的 24px 正是内层 td 的
     左右各 12px 内边距（旧写法 padding 挂在 <span> 上没生效）

  ⚠ 一条被实测推翻的预设（留档，别再照抄）：
    原以为「旧写法的 span 底色是锯齿状，短行只铺到文字末尾」，
    Qt 实测**不成立** —— 行内 span 的底色同样只覆盖文字范围、看着也是矩形。
    所以这次把底色挪到 td 的实际收益是**内边距生效**，
    不是"把锯齿背景变成矩形"。

【1.9.0 修订 · W2】气泡底色改为「自绘圆角」（你反馈：气泡要圆角）
────────────────────────────────────────────────────────────────
为什么不能靠 CSS：实测 Qt 富文本**三种写法全部忽略 border-radius**
（背景+圆角写 <td> / 写 <table> / bgcolor+style），四角填充都是 4/4 = 方角；
同一台机器上 QLabel + QSS 圆角却正常。
顺带发现：file_card_html 的"圆角卡片"（1.8.2 报告里写的）也从没落地，一直是方角。

又不能"把方角遮掉"：实测 Qt 给**嵌套表格**画底色的位置与
frameBoundingRect() 差 (6, 2) px，遮角要么遮不干净、要么切过头，
而且依赖这个偏移量会随布局变化而失效。

定稿做法：**底色不由 HTML 画**（HTML 只留内边距），由 _RoundedBubbleBrowser
在 paintEvent 里、**文字之前**用 QPainter.drawRoundedRect 画。
（已实测：super().paintEvent() 不会擦掉预画内容，文字正常叠在上面。）

几何（自洽 —— 画出来的就是我算出来的）：
  · 气泡矩形 = 该消息「1×1 气泡表格」内**非空文本块**的并集，四周各扩内边距。
    不能对整个消息区间求并集：表格会带出"结构性空块"（boundingRect 报的是
    整格可用宽度，实测 326/380），还会带出头像块。
  · 内边距 12×8、圆角半径 12（chat_widget.py 顶部 BUBBLE_PAD_X / _Y / RADIUS）
  · 只有底色非 transparent 的消息才登记气泡区间（bubble_spans）

实测数字（tools/dev_tests/_test_a190.py，抓 viewport 画布量像素）：
  · 短消息「测试圆角气泡看看四角」：算出矩形 x∈[179,332] y∈[13,43] = 154×31；
    实测绘制 x∈[179,332] y∈[13,43] —— **完全一致**
  · 四角仍是气泡色：0/4（真的圆角）
  · 左内边距处 = #dddddd（气泡确实画出来了）
  · 短消息不铺满整行；多行逐行起点离散度 0px（旧写法 312px）

⚠ 仍未做：文件卡片（jmcomic / B站 / office 那些）目前还是**方角** ——
  它用的是 Qt 自己画的 <table bgcolor>。要一起圆角，把它的底色也改由
  _RoundedBubbleBrowser 画（登记区间 + 颜色）即可，等你说。
