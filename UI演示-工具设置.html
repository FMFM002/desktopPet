v4 相对现状（Qt 版）只改一件事：
① 上下两个子窗口从 "分组框（带标题条）里再嵌一个滚动框" 改成 一行纯文字标题 + 一层内容滚动区 —— 就是 LLM API 页那种"标题下面直接是内容"的观感， 少一层边框、少一层视觉嵌套；
② 加载策略下拉保留三档（关闭 / 按需 / 常驻），宽度只装得下两个字；
③ action 设置页的「禁用框 / action 名 / 简介」列宽与间距收紧，长简介不再被窗口挡住；
④ 其余（下载路径在最左栏最下、默认图、idle_talk 设置项、主窗口不滚动）与现在一致。

等你点头：我就照这版把 Qt 的「工具设置」页改成单层窗口结构。
