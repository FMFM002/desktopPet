## 搬进来的正确时机

**新工具能顶替它之后**，再执行：

1. 确认新工具已经能画出图（不是"代码写完了"，是**真的出图了**）；
2. 把这三个文件**整体复制**到这里（复制，不是剪切 —— 先让两边并存一段时间）：
   ```
   tools/comfyui_tool.py          ← 给模型用的工具壳（描述/参数/分发）
   src/core/comfyui_client.py     ← 跟 ComfyUI 说 HTTP 的客户端
   src/core/comfyui_jobs.py       ← 后台任务与回调
   ```
3. 在下面「已归档」里登记一行（**从哪个提交来的、为什么退**）；
4. 再删原件，并**同步删掉对它的引用**（main_window / tool_manager /
   direct_dispatch_window）与 `_test_comfyui_191.py`；
5. 跑全量回归确认 FAIL=0。
