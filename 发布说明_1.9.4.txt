 铃兰桌宠（PRTS Desktop Pet） v1.9.4 发布说明（草稿）
══════════════════════════════════════════════════════════════════
 本版主题：**发布就绪** —— 把一个"只有作者能跑"的开发目录，
 变成"别人能装、能跑、能改设置"的正式版本。

──────────────────────────────────────────────────────────────────
 一、怎么装（三种形态，按省事程度排）
──────────────────────────────────────────────────────────────────
 A) 便携 zip（76.9 MB）
     解压 → 双击「启动.bat」。需要你自己有 Python 3.10~3.12。
     首次启动会自动装依赖（要联网）。

 B) exe（403.2 MB）
     解压 → 双击 `PRTS-DesktopPet-1.9.4.exe`。什么都不用装。
     ★ 说明：PyInstaller 打的包**被杀软误报是常态**，这是它的固有现象。

 C) 安装程序（installer/PRTS.iss，需 Inno Setup 6 编译）
     双击安装 → 开始菜单/桌面快捷方式/卸载项。
     安装过程中会**问你**要不要一起把模型装好（约 2.4 GB，默认不勾）。

 ★ 三种形态都**不包含模型**（否则包会从 77 MB 变成 2 GB 级）。
   模型按需获取，见第四节。

──────────────────────────────────────────────────────────────────
 二、第一次用
──────────────────────────────────────────────────────────────────
 启动后会弹出**首次配置引导**（五步）：
   1. 它先自己检查你的电脑，把"已自动发现 N 项"列给你看；
   2. **只问你 1 件事：LLM API Key**（去 https://platform.deepseek.com 申请）
      —— 可以点「测试一下」当场验证；
   3. 让你勾选用得上的能力 —— **这一页只有勾选框和说明**；
   4. **按你勾的来检查**（只列出你勾了的东西，**没勾的一个字都不显示**）：
      · 缺的模型可以 **① 把本地已有的路径填进去，我扫描确认后写进配置**
        （指模型目录本身、或指它的上一级都认），或者 **② 我来下载**
        —— 下载过程**就显示在这一页**，你看得见它在动；
      · **已经就位的不给你填路径的框**（没东西可填，给了只会让你卡住）；
      · **Ollama** 点「检测」会**替你试着启动一次**；
        **ComfyUI** 要先自己启动（双击它的 `run_nvidia_gpu.bat`），再点「检测」；
      · **本地语言模型**：按你的电脑配置（显卡/内存）推荐一档，
        把**型号和体积**先告诉你，**你确认了**才会开始下载（不会重复下已有的）；
   5. 告诉你"写了什么、写到哪、在哪能改"。

 · 引导**可以整个跳过**（关掉窗口即可），以后随时在**右键桌宠 → 设置**里配。
 · **已经配好 Key 的老用户不会被弹窗打扰**（判据：只差 LLM Key 才算首次）。

──────────────────────────────────────────────────────────────────
 三、配置与数据放在哪
──────────────────────────────────────────────────────────────────
   .env          密钥（DEEPSEEK_API_KEY 等）—— **绝不进版本库**
   config.json   界面/工具开关/角色等运行配置 —— **1.9.4 起已从版本库移除**
   data/DBs      聊天记录与长期记忆
   data/models/  ★ 模型（本版起**集中**在这里）
   logs/         运行日志

 ★ `config.json` 不在也没关系：首次运行会从随包的**出厂配置
   `config.default.json`** 自动生成一份。
 ★ 出厂自带两个**预设形象**：`deepseek` 与 `铃兰`（含各自的人设与头像）。

──────────────────────────────────────────────────────────────────
 四、模型是**按需获取**的（不随包）
──────────────────────────────────────────────────────────────────
   能力        需要什么                     大小
   TTS 语音合成  data/models/genie          约 1855 MB
   STT 语音识别  data/models/whisper         约 465 MB
   OCR 文字识别  data/models/easyocr         约 100 MB
   本地画图      外部 ComfyUI 服务            —

 ★ **缺这些不影响启动**：它们都是**可选能力**，没有只是对应功能不可用
   （本版专门为此加了守卫，确保"缺依赖只是少功能，不是崩"）。

 ★ **你本地已经有一份？别重复下载** —— 在引导第 4 步把路径填进去，
   它会**扫一遍（看目录本身和它的一级子目录）**、确认是对的模型后写进配置。
   （指模型目录本身、或指它的上一级都可以。）

 ★ **本地语言模型（可选）**：引导里能按你的**显卡/内存**推荐一档
   （如 `qwen2.5:7b`），把型号和体积告诉你、**你确认后再下**。
   Ollama 本体需要你自己装（https://ollama.com/download）—— 我们**不替你装软件**。

   管理命令：
     python tools/model_manager.py status             # 看现状
     python tools/model_manager.py migrate --dry-run  # 把旧位置的模型集中过来（先看）
     python tools/model_manager.py install --all      # 获取缺失的（会问，加 --yes 才真下）

──────────────────────────────────────────────────────────────────
 五、本版做了什么
──────────────────────────────────────────────────────────────────
 1. **版本信息统一**：以前 README 写 v1.8.9、启动日志写 v1.5.0、主窗口写 v1.2.0，
    三个数字互相矛盾。现在**唯一来源是 `src/version.py`**，并有守卫自动核对
    （README 标题必须等于它，全仓不许有漂移的版本号）。

 2. **能独立运行**：
    · `jmcomic` / `genie_tts` 以前是"仓库外可编辑安装"，换机器就废 ——
      现在缺了只是对应工具不可用（会给出 `pip install jmcomic` 这类指引）；
    · `requirements.txt` **重写过**：旧版把 PDF/Word/PPT/剪贴板等依赖**只写在注释里**，
      而 `pip install -r` **不执行注释** → 装完少功能却不报错。现已全部真正声明，
      并删掉 4 个全仓 0 引用的多余包。

 3. **个人信息不随包**：发布装配器把密钥、聊天记录、日志、私有目录一律排除
    （有守卫盯着，含反向守卫）。`config.json` 从版本库移除。

 4. **首次配置引导**（见第二节）。

 5. **三种发布形态**（见第一节）+ **发布前自检**：
      python tools/preflight.py        # 一条命令看清"离发布还差什么"

──────────────────────────────────────────────────────────────────
 六、★ 已知问题 / 未验证项（如实列出，别当成已解决）
──────────────────────────────────────────────────────────────────
 · **A 形态**：开发机上验证过"解压 → 启动 → 弹出配置引导"全通，
   但**没有真正填 Key 聊过天**（那需要真人交互）。
 · **B 形态（exe）**：构建成功（403 MB）但**从未被真正运行过** ——
   开发沙箱里启动 GUI 进程会挂住。若你双击没反应，把 `PRTS.spec` 里的
   `console=False` 改成 `True` 重新打包，就能看到早期报错。
 · **C 形态**：`.iss` **只做过静态校验，没有被编译过**（开发机没装 Inno Setup）。
 · `_test_a190` 里"真实语音转写"仍是 **SKIP**：本机没装 SAPI 语音、原语音素材已丢。
   whisper 这条链路的**结构性验证**（参数固化/JSON 解析/兜底/坏输出）已由
   `_test_whisper_structural_194.py` 覆盖 15 条，所以不是盲区，只差"真语音"。
 · 环境地雷（与代码无关）：若你的 Python 安装目录里存在 **GBK 编码的 `.pth`**
   （某些中文项目会留），**Python 会全线启动失败**。排查：`python -c "print(1)"`
   若报错，就去 `Lib/site-packages/*.pth` 找。
